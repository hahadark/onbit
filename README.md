# 온빛 · Photo Tone Desktop

Windows 독립 실행형 사진 뷰어 / AI 보정 / HEIC 변환 / 일괄 리사이즈 프로그램입니다.
PySide6의 네이티브 Windows 창을 사용합니다. 웹 브라우저, 웹뷰, 로컬 웹 서버는 사용하지 않습니다.

## 실행

**이 GitHub 저장소는 소스 코드 배포본입니다.** 실행 파일, 모델 가중치, 개인 사진과 작업 목록은 포함하지 않습니다.
처음 복제했다면 아래 **개발 환경 / 빌드** 순서로 설치하고 [모델 준비 안내](models/README.md)를 따라 주세요.
아래 EXE 실행 안내는 로컬 빌드가 완료된 폴더에 해당합니다.

**`dist/Onbit/Onbit.exe`를 더블클릭**하세요. 프로젝트 폴더의 `실행.cmd`도 같은 프로그램을 엽니다.
완성된 `dist/Onbit` 폴더에는 Python, Qt, HEIC 코덱, AI 모델, CUDA 실행 라이브러리가 포함되어 있습니다.
별도의 Python / HEVC 스토어 코덱 / CUDA Toolkit 설치가 필요 없습니다.
프로그램을 다른 위치로 옮길 때는 **`Onbit.exe`와 `_internal`이 있는 Onbit 폴더 전체**를 옮기세요.
NVIDIA GPU를 사용하려면 NVIDIA 드라이버가 설치되어 있어야 합니다. GPU가 없으면 CPU로 처리합니다.

## 사진 보기와 보정

- 사진 열기 / 폴더 가져오기 / 드래그 앤 드롭. 폴더는 하위 폴더도 검색합니다.
- 지원 입력: JPG(다중 이미지 MPO JPEG 포함), MPO, PNG, WebP, TIFF, BMP, **HEIC / HEIF / HIF**.
- 파일 선택 창의 여러 파일 선택, 한글 파일명과 경로 지원. 중복 입력 경로는 한 번만 등록합니다.
- 왼쪽 목록에서 사진을 고르고, 휠 확대·축소 / 드래그 이동 / 더블클릭 화면 맞춤을 사용합니다.
  확대하면 멈춘 뒤 약 0.2초 안에 보이는 영역을 **원본 해상도**로 다시 그립니다(보정·LUT·매칭·피부 보정 모두 반영).
- 라이브러리는 **썸네일 격자 / 목록**을 전환할 수 있습니다. 여러 항목을 선택해 한꺼번에 빼거나
  **전체 비우기**를 사용할 수 있으며, 두 기능 모두 원본 사진 파일은 삭제하지 않습니다.
- 뷰어 하단에는 **셔터 속도, 조리개, ISO, 해상도**를 항상 같은 순서로 표시합니다.
  촬영일·카메라·렌즈·초점거리는 해당 정보가 있을 때 마우스를 올려 확인할 수 있습니다. GPS는 표시하지 않습니다.
- **비교**: 원본과 보정본의 구분선을 드래그. **원본** 버튼 또는 뷰어에 초점을 둔 상태에서 Space로 원본 보기.
- **AI로 자연스럽게 보정**은 사진을 분석해 AI 강도(기본 35%, 과한 채도·하이라이트 변화 시 20%),
  노출·색온도·색조·명암·채도를 제안합니다. 결과는 각 슬라이더에 표시되며 직접 수정할 수 있습니다.
  AI 모델과 이미지 통계 분석을 함께 사용합니다. 얼굴이 감지되면 피부 보정 30%를 함께 제안합니다.
  추천값은 밝고 화사한 톤을 기준으로 합니다. 중간 밝기를 조금 높게 잡고, 흐린 밝은 영역은 하이라이트를 올려
  환하게 만들며, 흰색이 날아가기 직전인 사진은 하이라이트를 내려 보호합니다. 색온도는 약간 맑은 쪽으로 맞춥니다.
- 노출, 대비, 하이라이트, 그림자, 색온도, 색조, 채도, 피부 보정, 부드러운 톤을 조절합니다.
- **피부 보정**은 두 가지 AI 모델을 로컬에서 사용합니다. **YuNet**이 정면뿐 아니라 옆으로 돌리거나 기울인 얼굴,
  화면을 채운 셀카부터 단체 사진의 작은 얼굴까지 찾고, **얼굴 파싱(BiSeNet)**이 얼굴마다 피부·코·귀·목을
  픽셀 단위로 나눕니다. 그래서 실제 얼굴 모양대로 피부만 보정하고 눈·눈썹·입술·치아·머리카락은 건드리지 않습니다.
  경계 보존 필터(가이디드 필터)를 얼굴 크기에 맞춘 반경으로 적용하므로 모공·잔잡티는 고르게 하면서 윤곽은 유지하고,
  미리보기와 고해상도 저장 결과가 같은 느낌입니다. 피부 톤도 살짝 밝게 정리합니다.
  얼굴 인식과 분할은 CPU(얼굴당 약 0.15초, 사진별로 한 번만 계산), 보정은 CUDA GPU를 사용합니다.
  완전한 옆모습, 아주 작은 얼굴, 마스크·손으로 많이 가린 얼굴은 놓칠 수 있으니 결과를 비교하고 강도를 조절하세요.
  모델 파일이 없으면 기존 방식(정면 얼굴 검출과 피부색·타원 마스크)으로 동작합니다. 잡티를 개별 제거하거나 얼굴 형태를 바꾸지는 않습니다.
- 내추럴 / 소프트 / 웜 필름 프리셋, RGB 히스토그램, 밝기·색감 분석.
- 부드러운 톤은 명암과 채도를 완만하게 다듬습니다. 피부 보정은 인물 섹션에서 별도로 조절합니다.
- 사진별 보정값과 체크 상태는 자동 저장됩니다. 목록에서 빼기는 원본 파일을 삭제하지 않습니다.
- 현재 사진의 보정값은 **현재 보정을 체크 사진에 적용**으로 선택한 사진들에 한 번에 복사할 수 있습니다.

### 계조 보완 (폰카 계조를 큰 센서처럼)

**밝기 → 계조 보완** 슬라이더(0~100%)는 폰 사진의 부족한 계조를 세 가지 방식으로 보완합니다.
AI 자동 보정은 30%를, HDR 게인맵이 있는 사진에는 50%를 제안합니다.

- **디밴딩**: 하늘·벽처럼 평평한 영역의 8비트 계단(층 지는 현상)만 부드럽게 폅니다.
  경계 보존 필터라 피부결·나뭇잎·윤곽 같은 실제 질감은 유지합니다.
- **하이라이트 롤오프**: 가장 밝은 톤을 필름처럼 완만하게 흰색으로 보냅니다. 한 채널만 먼저 잘려
  하늘이 청록색으로 틀어지거나 해 주변에 색 띠가 생기는 현상을 줄입니다. 강도를 높이면 순백색이 아주 조금 낮아집니다.
- **HDR 게인맵 복원**: 아이폰 HEIC(Apple HDR 게인맵)와 안드로이드 Ultra HDR JPEG에 함께 기록된 게인맵을 읽어,
  SDR 사진에서 하얗게 날아간 하이라이트의 실제 계조를 되살린 뒤 롤오프로 자연스럽게 담습니다.
  게인맵이 있으면 분석 영역에 표시됩니다. 게인맵이 없는 사진은 디밴딩과 롤오프만 적용됩니다.
- **디더링**: 보정 결과를 8비트로 저장할 때 위치 기반의 미세한 노이즈를 섞어 반올림 계단이 다시 생기지 않게 합니다.
  계조 보완 값과 관계없이 보정한 모든 사진에 적용되며, 순수한 검정·흰색과 보정하지 않은 사진은 그대로 둡니다.

한계: 폰 센서가 기록하지 않은 정보를 만들어 내지는 않습니다(게인맵은 실제 기록된 정보입니다).
Apple 게인맵의 사진별 헤드룸 값은 제조사 메타데이터를 읽지 않고 일반적인 값(2.3스톱)을 사용하며,
iOS 18 이후의 ISO 21496-1 형식 HEIC 게인맵은 아직 읽지 않습니다. 거꾸로(180°) 저장된 HEIC는 게인맵을 사용하지 않을 수 있습니다.

### `.cube` LUT 색감

- 오른쪽 **LUT 색감**에서 표준 3D `.cube` LUT 파일을 **여러 개 한 번에** 불러옵니다.
- 불러온 LUT는 목록에 남습니다. 목록에서 클릭하거나 ↑↓ 키로 옮기면 현재 사진에 바로 적용되어 미리보기로 비교할 수 있습니다.
  맨 위 **LUT 없음**을 고르면 원래 색감으로 돌아갑니다. **목록에서 빼기**는 목록에서만 뺍니다.
- **☆ 즐겨찾기** 버튼 또는 목록 더블클릭으로 자주 쓰는 LUT에 별표를 붙입니다. 즐겨찾기는 목록 위쪽에 모이고,
  **즐겨찾기만**을 체크하면 즐겨찾기 LUT만 ↑↓ 키로 넘겨 보며 비교할 수 있습니다.
- 표준 LUT 형식: 2~65 크기의 LUT와 `DOMAIN_MIN / DOMAIN_MAX`를 지원합니다.
- LUT는 AI·밝기·색감 조정 뒤에 RTX GPU로 적용되며 강도를 0~100%로 조절할 수 있습니다.
- 화사한 LUT는 먼저 40~70%에서 미리본 뒤 조절하는 것을 권장합니다.
- LUT 파일은 복사하거나 수정하지 않습니다. 사진 설정에는 파일 경로와 강도만 저장되므로 LUT 파일을 옮기거나 삭제하면 다시 선택해야 합니다.
- **현재 보정을 체크 사진에 적용**을 누르면 선택한 LUT와 강도도 함께 복사됩니다.

## 일괄 처리

1. 왼쪽 목록에서 처리할 사진의 체크박스를 선택합니다. **전체 체크**로 한 번에 선택할 수 있습니다.
2. 오른쪽 위 **일괄 작업 · N장**을 누릅니다. 별도 팝업 없이 기본 창이 일괄 작업 화면으로 전환됩니다.
3. **출력 형식**: JPG, PNG, WebP, HEIC, TIFF, BMP 중 하나를 선택합니다.
4. **보정 방식**: 사진별 저장값, 자연스러운 AI 자동 보정, 기준 사진에 색감·밝기 맞추기,
   현재 사진의 설정 공통 적용, 색 보정 없이 변환·리사이즈 중 하나를 선택합니다.
   AI 자동 보정은 사진마다 별도로 분석합니다. 세부 설정에서 전체 AI 강도, 색감·화이트밸런스,
   밝기·명암, 부드러운 톤, 얼굴 피부 보정 강도를 지정할 수 있습니다. 피부 보정은 얼굴이 인식된 사진에만 적용됩니다.
5. **크기 조절**: 원본 크기 유지 / 긴 변 기준 픽셀 / 가로 × 세로 범위 안에 맞추기 /
   원본 대비 비율(%) 중 하나를 선택합니다. 비율을 유지하며 사진을 자르지 않습니다.
6. 작은 사진의 확대가 필요할 때만 **작은 사진도 확대 허용**을 선택합니다.
7. JPG / WebP / HEIC의 기본 품질은 90입니다. 기본값은 각 원본 폴더 안에 `온빛_내보내기`
   하위 폴더를 자동 생성하며, 원하면 하나의 지정 폴더로 바꿀 수 있습니다.
8. RTX GPU 병렬 처리를 켜면 서로 다른 사진 두 장의 AI 작업을 별도 CUDA 스트림에서 동시에 처리합니다.
   8GB RTX 3070 기준 2장으로 제한하며, CPU 환경이나 색 보정 없는 변환은 순차 처리합니다.
9. 사진에 저장된 `.cube` LUT가 있으면 AI 보정 뒤에 함께 적용합니다. **색 보정 없이 변환·리사이즈만**에서는 LUT도 적용하지 않습니다.

진행률과 파일별 결과를 확인할 수 있습니다. **현재 파일 완료 후 중지**를 누르면 완료된 결과는 남기고
다음 파일부터 처리하지 않습니다. 깨진 사진 한 장이 있어도 다음 사진으로 계속 진행합니다.
결과 표의 파일명에 마우스를 올리면 전체 경로가 표시됩니다. 완료 후 **결과 폴더 열기**로 확인합니다.
원본과 기존 출력은 덮어쓰지 않습니다. 같은 이름은 `_001`, `_002` 등 번호를 붙입니다.
처리 결과 / 실패 이유 / 설정을 기록한 `onbit-report-날짜-번호.json`도 출력 폴더에 저장합니다.
**현재 사진 저장**은 동일한 저장 옵션으로 현재 사진 한 장만 처리합니다.

### AI 색감 매칭 · 기준 사진 따라가기

오른쪽 **색감·LUT** 탭의 **색감 매칭**에서 기준 사진의 밝기와 색감을 다른 사진에 맞춥니다.

1. 원하는 톤의 사진을 고르고 **★ 현재 사진을 기준으로 지정**을 누릅니다. 라이브러리에 ★가 붙습니다.
   기준 사진의 보정값·LUT가 적용된 **현재 결과**가 기준이 됩니다.
2. 방식에서 **AI 색감 매칭 · Neural-Preset**(기본값)을 선택합니다. 다른 사진에서 **현재 사진 맞추기**를
   누르거나, 여러 장을 체크하고 **체크한 사진 맞추기**를 누릅니다. 이전 통계 매칭도 다시 누르면 AI로 바뀝니다.
   맞추기는 사진에 기준을 지정만 하므로 몇 장이든 바로 끝납니다. 실제 계산은 **그 사진을 미리보기로 열 때**
   그 사진만 하고, 일괄 처리에서는 아직 계산하지 않은 사진만 내보내면서 계산합니다. 첫 AI 매칭은 모델 로딩 시간이 추가됩니다.
   계산 결과는 저장되어 다시 열 때는 계산하지 않습니다. **비교**로 원본과 확인할 수 있습니다.
3. 매칭은 사진마다 보정 레이어로 저장됩니다. **매칭 강도**(기본 80%), **밝기도 맞추기**, **피부색 보호**는
   언제든 바꿀 수 있고 다시 계산하지 않습니다. **매칭 해제**로 원래대로 돌아갑니다.
   기준 사진을 바꾸거나 기준 사진의 보정을 크게 바꿨다면 **맞추기**를 다시 눌러 주세요.
   **매칭된 사진 모두 함께 조절**(기본 켜짐)이면 같은 기준에 맞춘 사진 전체가 함께 바뀌고, 끄면 현재 사진만 바뀝니다.
   기준 사진을 보고 있을 때도 매칭된 사진들의 강도를 한꺼번에 조절할 수 있습니다.
4. 사진별 슬라이더와 LUT는 매칭 뒤에도 그대로 조절할 수 있습니다. 일괄 처리의 **사진별 저장값**은 저장된 매칭을 포함해 내보냅니다.

맞추는 방식:
- **AI 모드**: 학습된 EfficientNet 신경망이 대상 사진의 원래 색감을 정규화하는 변환과 기준 사진의 색감을
  입히는 변환을 각각 예측합니다. 두 변환을 결합해 원본 해상도에 적용하므로 사진마다 결과가 다릅니다.
  공개 Neural-Preset의 **비공식 연구 구현(DY112)** 가중치를 사용합니다. Luminar의 모델이 아닙니다.
- 대상·기준 사진의 현재 보정값과 `.cube` LUT를 반영한 축소 사진을 분석합니다. 전체 밝기·채널 간 색 관계를
  학습으로 추정하는 **전체 사진용 RGB 행렬**이며, 같은 물체나 피부·하늘을 양쪽 사진에서 대응시키는 모델은 아닙니다.
  촬영 조명이 크게 다르거나 일부 색이 날아간 경우 완벽히 복원하지 못하며, 모든 장면에서 기존 방식보다 좋지는 않습니다.
- **밝기도 맞추기**를 끄면 원래 지각 밝기를 보존하며 색감을 적용합니다. **피부색 보호**를 켜면 얼굴 AI 마스크로
  피부색 변화를 막습니다. AI 모드에서는 밝기 맞춤이 켜져 있으면 피부의 밝기는 함께 조절합니다.
- **기존 방식 · 밝기·색 분포 맞춤**도 선택할 수 있습니다. 밝기 분포 13개 지점과 암부·중간·밝은 영역의 색 통계를
  맞추며, 이 방식의 피부 보호는 밝기까지 보존합니다. 예전에 저장한 매칭은 기존 결과를 유지합니다.
- AI는 RTX GPU에서 실행하고 GPU가 없으면 CPU를 사용합니다. 가중치 약 19MB는 앱에 포함되며 사진을 업로드하지 않습니다.
  모델 파일이 없거나 손상되면 오류를 표시합니다. 통계 방식을 몰래 대신 적용하지 않습니다.

매칭 상태에 **AI Neural-Preset / cuda** 또는 기존 통계 방식이 표시됩니다. 장면이 크게 다르면 강도를 낮추거나
기준 사진을 나눠 쓰세요. **현재 보정을 체크 사진에 적용**은 매칭을 복사하지 않습니다(사진마다 따로 계산해야 합니다).
일괄 처리의 **기준 사진에 색감·밝기 맞추기**에서도 AI/기존 방식·강도·밝기·피부 보호를 선택할 수 있으며,
★로 지정한 기준 사진과 그 보정·LUT를 사용합니다. 기준 사진 자체에는 매칭을 중복 적용하지 않습니다.
신경망과 피부 모델의 연구용 데이터·배포 조건은 `third_party/NOTICE.md`를 확인하세요.

## 로컬 처리와 저장 위치

- 사진을 외부 서버로 전송하지 않습니다. 설치된 모델과 코덱만으로 오프라인 실행됩니다.
- RTX 3070 8GB에서 CUDA 추론과 HEIC 입력 / 6가지 출력 형식을 검사했습니다.
- AI 모델은 전체 사진을 축소해서 이미지별 LUT를 예측합니다. 색 변환은 192행 단위로 처리하며
  일괄 처리에서는 최대 2장을 별도 CUDA 스트림으로 처리합니다. CUDA 메모리 부족 시 해당 엔진은 CPU로 전환합니다.
- 프로그램 설정: 실행 폴더의 `onbit-data/library.json`.
  실행 폴더가 쓰기 금지인 경우 `%LOCALAPPDATA%/Onbit`을 사용합니다.
- 출력 기본값: 각 원본 폴더의 `온빛_내보내기`. 일괄 작업 화면에서 폴더 이름을 바꾸거나
  실행 폴더의 `exports` 또는 원하는 단일 폴더로 변경할 수 있습니다.
- 원본 파일은 복제하거나 수정하지 않고 경로를 기억합니다. 원본을 옮긴 경우 다시 가져와 주세요.
- EXIF 방향을 적용하고 내장 ICC 프로필을 sRGB로 변환합니다.

## 현재 처리 범위

보정·변환은 **8비트 RGB / sRGB** 기반입니다. RAW 현상, 10/16비트 및 HDR 보존은 지원하지 않습니다.
HEIC는 주 이미지를 사용하며 Live Photo 동영상, 깊이 정보, 보조 이미지, HDR 게인맵을 출력에 보존하지 않습니다.
MPO JPEG도 첫 번째 대표 이미지만 처리하고 보조 이미지·게인맵은 보존하지 않습니다.
HDR HEIC의 명암은 원본을 지원하는 HDR 뷰어와 다를 수 있습니다. 투명도는 흰 배경에 합성합니다.
내보낸 파일에 원본 EXIF/GPS를 복사하지 않습니다. 지원하는 출력에는 sRGB ICC를 포함합니다(BMP 제외).
입력과 확대 후 출력은 6,000만 화소 이하입니다. 미리보기는 긴 변 1600px이고 확대한 영역은 원본 해상도로 표시하며, 내보내기는 지정한 해상도로 처리합니다.

## 개발 환경 / 빌드

Python 3.12 개발 환경에서 다음 순서로 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File setup.ps1
# models/README.md에 따라 모델을 준비하고, samples/README.md에 따라 샘플을 준비합니다.
.\.venv\Scripts\python.exe desktop.py
powershell -ExecutionPolicy Bypass -File build.ps1
```

`setup.ps1`은 프로젝트 가상환경에 패키지를 설치합니다. 얼굴 인식용 OpenCV와 CUDA 포함 PyTorch 다운로드는 약 3.3GB입니다.
`build.ps1`은 `dist/Onbit`에 실행 파일과 동작에 필요한 라이브러리를 묶습니다.
빌드 및 전체 테스트에는 [모델 파일](models/README.md)과 [샘플 사진](samples/README.md)이 필요합니다.

검사:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\dist\Onbit\Onbit.exe --self-test "$env:TEMP\Onbit-self-test"
```

두 번째 명령은 실제 EXE의 모델 / Qt / HEIC 인코더 / 디코더 / 6가지 출력 형식과 얼굴 검출·피부 보정 영역 보호를 점검하며,
결과를 지정 폴더의 `self-test.json`에 씁니다.
